# 기능 2 평가 요약

**한 줄 요약**: 처음 보는 공개 회의록(시험 세트)에서 꼭 찾아야 할 할 일 6개를 모두 찾았습니다. 담당자·기한을 잘못 확정한 경우는 0건이었습니다(0/18).

이 문서에는 집계 수치와 가상 예시만 씁니다. 평가에 쓴 공개 회의록의 원문·인물·안건은 저장소에 넣지 않습니다.

## 1. 무엇을 쟀나

| 지표 | 뜻 |
|---|---|
| 필수 항목 찾음 | 정답 표에서 "꼭 뽑아야 할 일" 중 시스템이 찾은 수 |
| 정밀도 | 시스템이 낸 할 일 중 정답 표(필수+선택)에 있는 비율. 선택 항목은 뽑든 안 뽑든 감점하지 않습니다 |
| 담당자·기한 정확 | 찾은 필수 항목 중 담당자·기한이 정답과 같은 수. 정답이 "미확정"이면 시스템도 확정하지 않아야 맞습니다 |
| **거짓 확정** | 정답이 "미확정"인 담당자·기한을 시스템이 확정해 버린 횟수. **가장 중요한 지표(목표 0)**입니다. 잘못 확정하면 엉뚱한 사람에게 일정과 알림이 가기 때문입니다 |

## 2. 평가 설계

| 세트 | 회의록 | 쓰임 |
|---|---|---|
| 가상 샘플 | 가상 팀 회의록 3개 | 개발용. 만들면서 계속 본 회의록이라 수치가 낙관적입니다 |
| 공개 회의록 개발 세트 | 국회 회의록 발췌 5개 | 개발용. 규칙을 다듬는 데 썼습니다 |
| **공개 회의록 시험 세트** | 발췌 5개(개발 세트와 다른 회의) | **공식 수치.** 모델에 넣은 적 없는 회의록입니다 |
| 보충 세트 | 발췌 3개 | 개인 담당·날짜 기한이 있을 법한 안건을 골라 만들었습니다(무작위 아님) |
| 블라인드 세트 | 규칙을 보지 않은 사람이 쓴 가상 팀 회의록 | 준비만 했습니다. 아직 회의록이 없습니다([BLIND_TEST.md](BLIND_TEST.md)) |

공정하게 재려고 네 가지를 지켰습니다.

1. **세트 구분**: 규칙은 가상 샘플과 개발 세트만 보고 다듬었습니다. 시험 세트는 마지막에 한 번만 돌렸습니다.
2. **규칙 동결**: 시험 세트를 돌리기 전에 규칙을 커밋 해시(`5f55091`)로 고정했습니다. 결과를 본 뒤에는 바꾸지 않았습니다.
3. **실행 전 라벨 확정**: 정답 표를 사람이 검수해 확정하고, 파일 해시를 기록한 다음에 모델을 돌렸습니다.
4. **원 출력 저장과 재채점**: 모델 응답을 그대로 저장했습니다. 규칙의 효과는 모델을 다시 부르지 않고, 같은 출력을 규칙을 켜고 끈 채로 각각 채점해 비교했습니다.

- 모델: Gemini function calling. `gemini-3.5-flash`가 실패하면 `gemini-3.5-flash-lite`, 다음은 `gemini-3.8-flash` 순서로 씁니다. 프롬프트는 v3입니다. 시험·보충 세트는 모두 `gemini-3.5-flash`에서 끝났습니다.
- 규칙 기반 기준선: 모델 없이 규칙만으로 뽑은 결과입니다. Gemini를 쓸 수 없을 때 앱이 이렇게 동작합니다.
- 도구: `scripts/eval_meeting.py`. `--plan`은 예상 호출 수만 보여 주고, `--save-raw`는 원 출력을 저장하고, `--rescore`는 호출 없이 다시 채점합니다.

## 3. 결과

### 모델 + 담당자 규칙 (실제 앱과 같은 조건)

| 세트 | 실행 | 필수 항목 찾음 | 정밀도 | 담당자 정확 | 기한 정확 | 거짓 확정 |
|---|---|---|---|---|---|---|
| 가상 샘플 (개발용·낙관적) | 2회 | 30/30 | 31/31 | 30/30 | 30/30 | 0/22 |
| 공개 회의록 개발 세트 | 3회 | 24/24 | 36/45 | 22/24 | 23/24 | 0/66 |
| **공개 회의록 시험 세트 (공식)** | 1회 | **6/6** | 9/10¹ | 6/6 | 6/6 | **0/18** |
| 보충 세트 (선별) | 1회 | 3/4 | 6/6 | 2/3 | 3/3 | 1/11² |

- 가상 샘플과 개발 세트는 규칙을 동결하기 전(2026-10-08)의 개발 단계 측정입니다. 저장해 둔 일부 출력을 최종 규칙으로 다시 채점해도 거짓 확정은 늘지 않았습니다.
- 시험·보충 세트는 최종 동결 규칙 `5f55091`로 쟀습니다.

### 기준선과 "규칙 끔" 비교

| 세트 | 규칙 기반 (모델 없음): 필수 찾음 · 거짓 확정 | 모델 + 담당자 규칙: 거짓 확정 | 같은 모델 출력, 담당자 규칙 끔: 거짓 확정 |
|---|---|---|---|
| 가상 샘플 | 13/15 · 0/6 | 0/22 | 0/22 |
| 개발 세트 | 2/8 · 0/4 | 0/66 | 7/66 |
| **시험 세트** | 2/6 · 0/10 | **0/18** | 1/18 |
| 보충 세트 | 2/4 · 0/6 | 1/11 | 1/11 |

규칙 기반 기준선은 최종 규칙으로 쟀습니다. 발언 전체를 할 일로 내므로 키워드가 우연히 맞기 쉬워, 찾은 수가 실제보다 후하게 나옵니다.

### 읽는 법

- **모델이 찾고, 규칙이 거릅니다.** 모델만 쓰면 기관장이나 기관의 약속을 개인 담당으로 확정한 경우가 개발 세트에서 7번(3회 실행 합계), 시험 세트에서 1번 나왔습니다. 담당자 규칙이 모두 "미확정"으로 돌렸습니다.
- **규칙 기반만으로는 부족합니다.** 거짓 확정은 없지만 할 일을 많이 놓치고, 담당자와 기한을 모두 사람이 채워야 합니다. 장애 대비용입니다.
- **보충 세트의 거짓 확정 1건**은 규칙의 빈틈입니다(아래 4절 예시 3). 동결 원칙에 따라 고치지 않고 [README](README.md)의 "알려진 빈틈"에 적었습니다.

## 4. 예시 (모두 가상)

**예시 1 — 기관장의 약속은 기관의 약속으로 봅니다**

> 가상부 차관 문해솔: 지원 기준은 다음 달 협의 때 다시 따져 보고 알려 드리겠습니다.

- 모델은 담당자를 "문해솔"로 제안했습니다.
- 차관은 기관장급이고 '직접'이라는 말이 없습니다. 그래서 규칙은 부처 차원의 약속으로 보고 담당자를 "미확정"으로 둡니다. 실제로 일을 맡을 부서와 사람은 확인 화면에서 사람이 채웁니다.
- 같은 사람이 "그 건은 제가 직접 챙겨서 금요일까지 보고드리겠습니다"라고 하면 개인 담당자로 확정합니다.

**예시 2 — "저희가"는 한 사람이 아닙니다**

> 가상청 청장 윤채원: 저희가 현장 점검 결과를 정리해서 보고드리겠습니다.

- 모델은 "윤채원"을 제안했지만, 주어가 "저희가"라서 기관의 약속으로 보고 확정하지 않습니다.
- 팀 회의에서 "김민준 주무관: 제가 금요일까지 정리하겠습니다"라고 하면 김민준과 그 금요일로 확정합니다.

**예시 3 — 규칙이 놓친 경우 (보충 세트의 거짓 확정)**

> 위원장 한가람: 다음부터는 여당 간사께서 일정을 미리 공유해 주시면 좋겠습니다.

- 모델은 담당자를 "여당 간사"로 제안했습니다. 규칙은 직함 '간사'를 떼고 남은 "여당"을 사람 이름처럼 확정했습니다.
- 정답은 "미확정"입니다. 상대가 받아들이지 않은 부탁이고, "여당"은 사람이 아닙니다.

## 5. 한계

- **표본이 작습니다.** 시험 세트의 필수 항목은 6개, 보충 세트는 4개입니다. "0/18"은 작은 표본에서 0건이었다는 뜻이지, 앞으로도 0건이라는 뜻이 아닙니다.
- **확정 능력은 아직 덜 쟀습니다.** 시험 세트의 필수 항목은 모두 "미확정"이 정답이었습니다. 개인 담당자나 날짜 기한을 맞게 확정하는지는 시험 세트로 재지 못했습니다. 보충 세트에도 개인 담당자 정답은 1개뿐인데, 그마저 인용 문제로 확정하지 못했습니다(틀리게 확정하지는 않음). 블라인드 세트로 보완할 계획입니다.
- **보충 세트는 무작위 표본이 아닙니다.** 개인 담당과 날짜 기한이 있을 법한 안건을 골랐습니다.
- **국회 회의록과 팀 회의록은 다릅니다.** 국회 회의록은 질의·답변이 중심이고, 기관장 발언이 많으며, 정해진 할 일이 드뭅니다. 팀 회의록에는 담당자 지정과 기한이 훨씬 많습니다. 실제 쓰임(팀 회의)에서의 성능은 가상 샘플과 블라인드 세트로 봐야 합니다.
- **가상 샘플 수치는 낙관적입니다.** 개발하면서 계속 본 회의록입니다.
- **모델 응답은 실행마다 조금씩 다릅니다.** 개발 세트를 3회 돌렸을 때 담당자 정확은 22/24였습니다.

---

¹ 시험 세트 정밀도 9/10에서 빠진 1건은 채점상 불일치입니다. 같은 약속을 뽑은 모델 항목의 문구에 선택 라벨의 키워드가 없었습니다. 라벨은 실행 전에 확정했으므로 고치지 않았습니다.

² 보충 세트의 거짓 확정 1건은 위 예시 3과 같은 경우입니다. 담당자 규칙을 꺼도 같은 결과라, 규칙이 막지 못한 경우입니다.
