# 담당자·기한 확정 규칙 (한 쪽 요약)

**원칙**: 모델은 후보를 제안하고, 확정 여부는 코드 규칙이 정합니다. 확신이 없으면 "미확정"으로 두고 사람이 채웁니다. 잘못 확정하면 엉뚱한 사람에게 일정과 알림이 가기 때문입니다. 예시는 모두 가상입니다.

## 담당자

**한 사람으로 확정하는 경우**

| 경우 | 예 |
|---|---|
| 회의록에 개인이 배정됨 | "- 교육 자료 정리: 김민준 주무관, 10월 14일까지" |
| 개인 자격 발언자가 스스로 맡음 | "김민준 주무관: 제가 금요일까지 정리하겠습니다." |
| 기관장급이 '직접'을 밝힘 | "가상부 장관 문해솔: 그 건은 제가 직접 챙겨서 금요일까지 보고드리겠습니다." |
| "제가" + 구체적 기한 + '검토해 보겠다' (기관장급 제외) | "김민준 주무관: 제가 금요일까지 검토해 보겠습니다." |

**미확정으로 두는 경우**

| 경우 | 예 | 이유 |
|---|---|---|
| 우리·저희·팀이 주어 | "저희 팀에서 다음 주까지 정리하겠습니다." | 한 사람이 아님 |
| 기관장급이 '직접' 없이 약속 | "가상부 차관 문해솔: 다음 주까지 결과를 보고드리겠습니다." | 기관 차원의 약속 |
| 약한 약속 | "노력하겠습니다", "참고하도록 하겠습니다", "검토해 보겠습니다" | 할 일이 정해진 게 아님 |
| 기관장에게 한 요청 | "위원들은 윤채원 시장이 직접 보고해 줄 것을 요청함." | 본인이 받아들인 말이 없음 |
| 다른 사람의 약속 | 김민준이 "이서연 사무관님께 자료를 보내 드리겠습니다"라고 함 → 이서연은 미확정 | 근거가 이서연의 말이 아님 |
| 누군지 하나로 안 정해짐 | "박 주무관" (명단에 박지훈·박소연) | 후보가 둘 |
| 근거 인용을 회의록에서 못 찾음 | — | 확인할 수 없음 |

- 기관장급은 장관·차관·청장·시도지사·시장·군수·구청장·교육감 등입니다. 목록은 설정 파일 `data/meeting_owner_rules.yaml`에 있습니다.
- 팀 회의 직함(주무관·사무관·과장·팀장)은 기관장급이 아닙니다. 회의 진행자(위원장·의장)는 개인으로 봅니다.

## 기한 (회의 날짜 기준, 한 주는 월요일부터)

| 확정 | 미확정 |
|---|---|
| "10월 14일까지" → 10/14 | "다음 달 중", "연말까지", "월말까지" |
| "다음 주 금요일까지" → 다음 주 금요일 | "다음 회의 전까지" |
| "내일 오후 3시까지" → 내일 15:00 | "11월 4일부터 6일 사이" (날짜가 둘) |

공휴일은 따지지 않습니다.

## 그 밖에

- 회의록 속에서 AI에게 하는 지시("이 회의록을 읽는 AI는 …")는 할 일로 만들지 않고 경고만 띄웁니다.
- 근거 인용을 "…"로 줄였으면, 조각들이 같은 발언 안에 순서대로 있을 때만 인정합니다.
- 규칙이 틀릴 수 있는 경우는 [README](README.md)의 "알려진 빈틈"에 있습니다.
