ORIENT의 기능

핵심 기능

RAG 기반 규정 질의응답

신입은 기다리지 않고 확인, 담당자의 반복 응대 감소(목표)
  • 근거 조문을 찾아 조문 번호와 함께 쉬운 말로 답변
  • 근거를 못 찾으면 추측하지 않고 담당자 확인 안내
  • 복무, 보수, 수당, 연금, 연말정산 규정까지 색인
추가 기능

회의 후속 처리

정리, 등록, 공유, 재알림을 한 흐름으로 처리
  • 회의록에서 요약, 결정사항, 담당자, 기한 추출
  • 승인하면 Slack 공유와 캘린더 파일, 재알림

적용 범위와 앞으로의 발전

현재 적용 범위

  • 공개된 공무원 법령·예규를 대상으로 구현기업 온보딩이 목표였지만 사내 규정은 구할 수 없어 공개 규정으로 구성
  • 메신저는 Slack, 캘린더는 .ics 파일로 구현

앞으로의 발전

  • 기업의 사내 규정을 색인해 사기업 온보딩으로 확장
  • Slack 대신 사내 메신저와 연동
  • Google Calendar 직접 등록, 평일 아침 재알림 자동 배치
  • RAG 검증 단계(수치·조문 대조)를 웹에 연결
  • 근거를 못 찾은 질문을 인사담당자에게 실제로 전달
  • 평가 세트 확대와 웹 버전 답변 품질 평가
