해결 방향

기능 1. 규정 질의응답

RAG + LLM
  • 근거 조문을 찾아 조문 번호와 함께 쉬운 말로 답변
  • 근거를 못 찾으면 추측하지 않고 담당자 확인 안내
  • 복무, 보수, 수당, 연금, 연말정산 규정까지 색인

기능 2. 회의록 후속 처리

추출, 검토·승인, 실행, 재알림
  • 요약, 결정사항, 담당자, 기한 자동 추출
  • 사람이 승인하면 Slack 공유와 캘린더 파일(.ics) 생성
  • 마감 전날, 당일, 기한 지남 단계별 재알림
공통 원칙모르면 추측하지 않고 '담당자 확인' 또는 '미확정'으로 표시해 사람에게 넘긴다
